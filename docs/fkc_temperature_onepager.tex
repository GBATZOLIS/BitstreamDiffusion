\section*{Setup}
CoBit = continuous VE diffusion over analog bits; denoiser posterior $D_\theta$, score $s_\theta=(D_\theta-x)/\sigma^2$; prompt clamped. Goal: principled low-temperature / annealed / guided sampling. We implemented \hl{A1} (local score-level temperature $\kappa(\sigma)=\tfrac{v+\sigma^2}{\tau v+\sigma^2}$, $v{=}0.25$), a \hl{Feynman--Kac Euler--Maruyama SMC sampler} (annealed $p_c^\beta$ and CFG/Prop-3.1 geometric average $q_u^{1-w}q_c^w$; \texttt{em} and \texttt{edm\_churn} proposals; weight $\tfrac12\beta(\beta{-}1)\Delta\sigma^2\lVert s\rVert^2_{\text{free}}$), and an \hl{entropy-band} resampling option. 16 correctness gates pass (incl.\ analytic 1-D Gaussian $\mathrm{Var}\!\to\!(v+\sigma^2)/\beta$).

\section*{Main conclusions}
\begin{enumerate}[label=\arabic*.]
\item \hl{The culprit is resampling, not tempering.} Genealogical resampling collapses the 16-particle cloud from $\sim$5.4 to $\sim$2 distinct solutions, destroying the coverage that makes voting work. Particle \emph{mean} accuracy stays $\sim$67\% throughout --- particles don't get worse, they get \emph{correlated}.
\item \hl{Tempered-drift + voting (resampling off) ties $\beta{=}1$ voting} (90.6 vs 90.8, within $n{=}512$ noise), with diversity preserved. So mild tempering neither clearly helps nor hurts; the FK \emph{correction} (resample-toward-the-weight) is the part that hurts.
\item \hl{The FKC path weight is not a correctness signal.} On the resampling-off run (full, unreset cumulative potential): highest-weight particle $63.9\%$ $<$ mean $66.9\%$; weight-weighted vote $88.5\%$ $<$ plain vote $90.6\%$. Using the weight to select/vote \emph{hurts}.
\item \hl{Coverage is diversity-bound.} Even $\beta{=}1$ yields only 5.45 distinct of 16 (limited stochastic diversity), so raw $K$ has diminishing returns ($K{=}32$ barely beat $K{=}16$).
\item \hl{A1 is the one lever that helps} --- small, monotone, collapse-free --- because it is a gentle deterministic score-sharpening with no importance weights to degenerate.
\end{enumerate}

\section*{What we do \emph{not} claim (post-review)}
Not established: that model confidence is unrelated to correctness (the voting gain suggests the opposite); nor that correctly-implemented FKC fails on CoBit. Untested links: \texttt{edm\_churn} weight at $\beta{>}1$ / finite $N{=}180$ (asymptotic only); carry self-conditioning vs the Markov-score assumption; mode-reweighting (gate tested variance only). CFG results confounded by a weak 20k-step, dropout-trained checkpoint.

\section*{Recommended next steps}
(i) \hl{Verify@K} using the Sudoku rule-checker (a label-free, near-exact correctness oracle) $\Rightarrow$ realizes pass@K $\approx$ \hl{94\%} for free (Track C, Phase 0).
(ii) \hl{Reward-guided SMC} (SVDD): replace the likelihood weight with the constraint-satisfaction reward --- steer trajectories toward \emph{correct} modes, not confident ones.
(iii) Decisive FKC audits: \texttt{never}-resample $\beta$-sweep (does any $\beta$ beat voting?); toy-mixture mode-reweighting \& $N$-convergence; self-conditioning ablation.
